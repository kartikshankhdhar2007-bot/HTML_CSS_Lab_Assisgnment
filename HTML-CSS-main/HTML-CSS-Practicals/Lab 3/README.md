# Assignment 3: Your First HTML Page

## 1. Experiment Title
Your First HTML Page

## 2. Aim
Create basic HTML pages using document structure, headings, paragraphs, text formatting, and a line break.

## 3. Software / Tools Required
HTML, text editor or IDE, web browser

## 4. Theory
HTML (HyperText Markup Language) structures web content. Elements are represented by tags. Headings express document hierarchy, paragraphs contain text, and `strong` and `em` add semantic emphasis.

## 5. Algorithm / Procedure
1. Create `first.html` with the HTML document structure, title `My First Page`, and one H1 heading.
2. Create `headings.html` with H1, H2, H3, and a paragraph.
3. Create `text-format.html` with two paragraphs; use `strong` and `em` on one word each and include a line break inside a paragraph.
4. Open each page in a browser and check the displayed content.

## 6. Program / Queries / Commands
```html
<!-- first.html -->
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, I am Asha.</h1>
</body>
</html>
``` 
For the other two files, use `<h1>`, `<h2>`, `<h3>`, `<p>`, `<strong>`, `<em>`, and `<br>` as required.

## 7. Input
The input is the text for the page headings and paragraphs.

## 8. Output
The browser tab should display `My First Page`; the page should show the large H1 heading. The other pages should show three heading levels and formatted paragraphs. Include browser screenshots.
